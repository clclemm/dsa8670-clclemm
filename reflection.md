## Reflection File

GitHub is not entirely new to me, as I used it during my undergraduate studies. However, at that time I used it more as a file repository where we would put things for my instructor to grade rather than as a tool for collaboration. Many of the concepts in this week’s readings were also already familiar to me through my role as a Product Owner. I work closely with a development team, so I regularly see commits, pull requests, branches, and work moving through different development environments. What I had not really thought about before was how those same concepts could apply to analytics work. 

One challenge I had during the assignment was figuring out how to actually see and work with my files from GitHub Desktop. After a little Googling, I figured out that I needed to open the repository in File Explorer, but that actually led me to question what the value of the Desktop version was when I could already view and edit the files on GitHub.com. As I worked through more of the assignment, I started to see where it could be useful, particularly for analytics projects. Collaboration on code does not really work the same way something like Google Docs does for other types of documents, especially when you need to actually run the files on your local computer. I see how GitHub could help bridge that gap by giving a team a shared place to collaborate and manage changes while still allowing each person to work with the files in the programs they actually need to use.
